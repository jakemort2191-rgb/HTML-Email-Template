# HTML Email Template

## About This Project

This project is part of my software and web development course. I'm using it to practise building an email template with HTML and CSS and learn how email design differs from a standard webpage.

The aim is to create a clean, well-structured email that looks good on different screen sizes and uses techniques that are suitable for email clients.

## What I'm Working On

- **HTML structure** – organising the email into sections such as a header, main content and footer.
- **Email-friendly layouts** – exploring table-based layouts where needed for better compatibility.
- **Inline CSS** – styling elements in a way that works with common email clients.
- **Typography** – choosing readable fonts, sizes and spacing.
- **Images and links** – adding images, buttons and links to the email.
- **Responsive design** – making the template easier to read on mobile devices.
- **Email compatibility** – understanding that different email clients support HTML and CSS differently.
- **Testing** – checking the layout and making adjustments where necessary.

## Technologies Used

- HTML
- CSS

## What I've Learned

This project gives me the chance to practise building a template for email rather than a normal webpage. I'm learning why email development has different limitations, why simple layouts are often more reliable and why testing across different email clients is important.

I'm also exploring how to balance the design with readability and compatibility.

## How to View the Project

1. Download or clone this repository.
2. Open the HTML file in a browser to preview the template.
3. Check the layout at different screen sizes.

Opening the file in a browser is useful for a basic preview, but it won't show exactly how the email will look in every email client.
